# Afterlife Intake

A static site (no build step). Files: `index.html`, `style.css`, `app.js`, `data.js`, `skull-tile.svg`.

## Deploy to GitHub Pages

1. Create a repo and put all five files plus this README at the repo root.
2. Push to `main`.
3. In the repo go to **Settings → Pages**, set **Source** to "Deploy from a branch", branch `main`, folder `/ (root)`.
4. Your site appears at `https://<user>.github.io/<repo>/` after a minute.

Progress is saved in the browser's localStorage. The "reincarnate" link at the bottom of the home page clears it.
